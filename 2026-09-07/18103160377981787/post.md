GPT-6 Astra 做遊戲真的開始有點誇張了 😂

有人直接用 Astra 重製經典遊戲《Paperboy》。

而且不是單純做個 2D 小遊戲而已：

－3D 場景、房屋、角色都做出來
－使用 Blender 建立模型
－直接在瀏覽器即時渲染
－還能繼續調整貼圖、角色、場景與遊戲體驗

作者也有提到，最初版本其實沒有現在這麼漂亮，後面花了很多時間在角色建模、Textures、瀏覽器效能和整體細節上。

所以現在的 AI 遊戲開發比較像：

「AI 幫你把製作能力直接拉高，但最後的質感還是取決於你怎麼調。」

以前做這種 3D Web Game，光建模＋程式＋渲染就可以搞很久。

現在已經開始變成：

想法 → Prompt → 可玩的 3D 世界 🤯

我覺得 GPT-6 Astra 在 Three.js / 3D / 遊戲這塊真的很值得繼續玩。
