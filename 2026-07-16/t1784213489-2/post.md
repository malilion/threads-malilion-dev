最近逛到一個超適合前端與設計工程師的寶庫
21st.dev
簡單說，它是一個現代化 UI 元件的開源市集，幫你把網站裡那些「看起來很高級，但自己刻會搞死人」的互動介面與特效全都整理好了。
－可以直接複製程式碼使用（主打 React、Tailwind CSS 與 Framer Motion）
－無縫相容於 shadcn/ui 等現代前端工作流
－收錄各種高質感按鈕、動態卡片、炫酷背景與微互動元件
－大幅節省手動調校 CSS 與複雜動畫的時間
我覺得它適合做 SaaS 產品落地頁 (Landing Page)、個人作品集，或是需要驚豔視覺的 Web App。很多時候網站要看起來有「高級感」，靠的就是這些互動細節的堆疊。
21st.dev 比較像是把這些神人等級的「前端動效與排版」，變成讓你隨插即用、快速拼裝的靈感素材庫。
https://21st.dev/@designali-in/components/shader-lines
