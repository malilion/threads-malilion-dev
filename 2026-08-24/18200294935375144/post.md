最近逛到一個很適合幫網站增加視覺效果的工具：OriginKit。

簡單說，它是一套免費的動畫元件庫，把那些「看起來很有質感，但自己從零刻會花不少時間」的互動效果整理成可以直接使用的元件。

－支援 React、Next.js、Vite 與 Framer
－可以直接取得元件原始碼放進專案
－有 Text、Image、Gallery、Cursor、Button、Background 等分類
－包含粒子、文字變形、圖片 Reveal、Carousel、Globe、動態背景等效果
－每個元件都有即時 Preview 與可調整參數
－可以選擇 CSS、Tailwind 或 CSS Modules
－還能透過 MCP 讓 AI Coding Agent 直接搜尋並取得元件。

我覺得 OriginKit 最方便的地方，是它不是只有一些普通的 Button 或 Card。
裡面很多都是專門替網站增加「記憶點」的效果。
