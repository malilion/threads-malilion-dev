最近逛到一個滿適合做（LLM）實戰開發的開源專案：Awesome LLM Apps (by Shubhamsaboo)。 
簡單說，它是一個「LLM 應用程式的實戰範例庫」，幫你把從零摸索 API 串接與應用架構的痛苦，轉化為一套只要複製範例碼就能瞬間跑起 AI 應用的開發加速器。
－豐富實戰範例：收錄 RAG、AI 代理、多模態視覺助理等數十種真實場景的完整開源專案。
－開箱即用的 Web UI：深度結合 Streamlit 等輕量框架，免寫複雜網頁語法就能打造互動介面。 －跨模型與框架整合：支援 OpenAI、Claude、Gemini 及開源模型，並涵蓋 LangChain 等主流開發框架。
－做中學的極低門檻：每個專案皆附帶清晰原始碼與執行步驟，助開發者無縫跨越理論與實作的鴻溝。
