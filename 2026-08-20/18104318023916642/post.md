最近逛到一個令人嘆為觀止的 3D 沙雕模擬器開源專案：tidewright。

簡單說，它是一個「完全在 GPU 上運行的真實沙灘模擬器」。最狂的是，這整個具備物理運算、渲染、九種藝術風格甚至龐大世界觀的遊戲，作者竟然只用「一個 Prompt」加上 Claude Code 就直接生成出來了！

－極致純粹的硬核堆疊：沒有使用任何遊戲引擎（如 Unity 或 Unreal）、沒有第三方函式庫、沒有素材檔、甚至不需要編譯建置。整個遊戲全靠一個 WebGL2 環境和約 7,000 行的原生 JavaScript 與 GLSL 寫成。
－變態級的物理顆粒運算：沙子完全遵守真實世界的「休止角」。乾沙最高只能堆疊 33 度，加水可以蓋得更陡，但水太多就會像湯一樣垮掉。空中的每一粒沙都是獨立計算的 GPU 粒子，整體沙量的運算誤差率甚至低於 0.04%。
－豐富的潮汐與沙盒模式：支援自由創作的「無盡模式」、享受日夜光影變化的「平潮模式」，以及必須跟時間賽跑、抵禦九波漲潮的「戰役模式」，還附帶各種鏟子、模具與滴水工具。
