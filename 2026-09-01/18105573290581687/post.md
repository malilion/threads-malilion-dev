最近逛到一個很適合拿來畫系統架構圖的 AI Agent Skill：Archify。
簡單說，它可以把「一個系統描述」或「整個程式碼 Repo」，直接轉成一張可以互動、可以驗證、可以分享的系統架構圖。
而且不是單純輸出 Mermaid。
Archify 會讓 Agent 先產生結構化的 Typed JSON IR，再經過驗證、Layout 與 Render，最後輸出成自包含的 HTML / SVG。
－支援 Cursor、Claude Code、Codex CLI、OpenCode
－可以直接分析 Repository 產生 Architecture Diagram
－也可以沒有 Repo，只靠文字描述建立系統圖
－支援 Architecture、Workflow、Sequence、Data Flow、Lifecycle 五種圖
－可以在 Dark / Light Theme 間切換
－提供多種 Visual Preset
－輸出 HTML、PNG、SVG、WebM
