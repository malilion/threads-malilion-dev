－提供單一 API 端點，支援超過 290 家供應商（其中 90+ 家有免費額度）與 500+ 種模型（包含 OpenAI, Claude, Gemini, DeepSeek 等） 
－完美相容 Cursor, Cline, Claude Code 等主流 AI 寫程式工具
－內建自動備援機制（Auto-fallback），當某個免費 API 額度用完時，會自動幫你切換到下一個 －具備 Token 壓縮技術，據稱可節省 15-95% 的 Token 消耗，並支援 MCP 協議。
