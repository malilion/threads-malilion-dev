最近逛到一個滿適合做室內設計與 3D 空間規劃的開源工具：OpenHome3D (by yuyou-dev)。

簡單說，它是一個「基於 Web 的開源 3D 室內設計引擎」，幫你把原本需要安裝龐大專業軟體（如 AutoCAD 或 SketchUp）才能完成的繪製格局、擺放家具與 3D 渲染，轉化為一套只要打開瀏覽器就能直接拖拉操作的輕量化設計平台。

－2D/3D 即時同步切換：支援在 2D 平面圖上快速繪製牆壁與隔間，並能瞬間無縫切換到 3D 立體視角，實現所見即所得的空間體驗。
－純網頁端高效能運行：底層基於現代 Web 3D 技術建構，無須下載安裝，在瀏覽器內就能流暢載入並編輯複雜的房間模型。
－自定義資產與模型支援：支援快速匯入自定義的門窗、家具與材質貼圖，具備高度擴充性，方便開發者建立專屬的模型庫。
－極易整合的開源架構：提供清晰的 API 與模組化設計，能輕鬆嵌入現有的房產平台、家具電商或家裝 SaaS 系統中。
