最近逛到一個很適合快速製作網站介面的開源工具：shadcn/ui。

簡單說，它整理了一套設計完成、支援無障礙操作的 UI 元件，讓你可以快速把按鈕、表單、卡片、Dialog、側邊欄、資料表等功能加入專案。
－可以依照自己的品牌調整配色、圓角、字體、間距與互動效果
－支援 Next.js、Vite、Laravel、React Router、Astro、TanStack Start 等開發方式
－支援社群 Registry，能安裝其他開發者製作的元件與模板
－可以建立自己的 Registry，分享公司內部或個人專案的設計系統
－也提供 Skills 與 MCP Server，讓 AI 助手讀取元件文件、搜尋元件並協助組合頁面。
我覺得 shadcn/ui 最方便的地方，是它同時兼顧了「快速開發」和「自由客製化」。
像是要製作登入頁、設定頁面或會員表單時，不需要每次都從零開始刻 UI；可以先加入現成元件，再直接修改裡面的 Tailwind 樣式與 React 程式碼。
