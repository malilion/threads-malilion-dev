最近逛到一個很適合拿來製作會員頭像的開源工具：DiceBear。

簡單說，它是一個 SVG 頭像產生器，可以透過名稱、使用者 ID 或任意字串，自動產生風格一致的個人頭像。

同一組字串每次都會產生相同的頭像，所以很適合用在會員系統、留言區、排行榜或遊戲角色資料中。

－內建超過 35 種頭像風格
－有人物、像素角色、Emoji、幾何圖形與 Identicon 等類型
－可以調整髮型、配色、背景、旋轉、縮放與圓角
－支援 SVG、PNG、JPG、WebP 等輸出格式
－可以直接透過網址 API 產生頭像，不一定要安裝套件

我覺得它最方便的地方，是不需要替每一位使用者準備圖片。
像是把使用者 ID 設成 seed，DiceBear 就會自動產生一張固定頭像。即使換裝置、重新載入頁面，也能得到同一個結果，不需要另外把圖片存進資料庫。
DiceBear 比較像是把「頭像素材庫、隨機角色產生器與開發 API」整合在一起。
很適合用在遊戲角色、匿名聊天室，或任何需要大量預設頭像的專案。
不過使用前記得確認個別頭像風格的授權。
