AI Coding 已經不只是幫你做網站了。

最近看到一個很猛的開源專案《長風 Long Wind》：

作者說自己一行程式碼都沒寫，靠 Claude Opus 5.5 + Claude Code，約 28 小時做出一款可以直接在瀏覽器玩的 3D 武俠動作遊戲。

而且不是小 Demo。

有草原、竹林、古鎮三個章節，還有攻擊、完美彈反、閃避、處決、劍氣、不同兵種與 Boss 戰。

最後規模做到：

－38,000 行 JS / GLSL
－151 個 Source Files
－Three.js
－Multi-Agent 分工開發

最有意思的是，它已經很像一間「AI 遊戲工作室」：

人類負責想要什麼，AI Agent 負責拆任務、寫程式、測試、Debug、整合。

以前 Vibe Coding 在做網站。

現在已經開始做完整 3D 遊戲了。
