最近逛到一個功能做得很完整的開源音樂播放器：NeriPlayer。 簡單說，它是一款原生 Android 音樂 App，把多平台線上播放、本地音樂管理、歌詞顯示和資料同步，全部整合在同一個播放器裡。
－整合網易雲音樂、Bilibili、YouTube Music 與本機音樂
－支援音樂下載、播放快取、本地歌單與離線播放
－有逐字高亮、翻譯、音譯、懸浮歌詞與狀態列歌詞
－播放頁有會隨著音樂變化的動態流體背景 －支援均衡器、響度增強、淡入淡出與 USB DAC 獨占播放
－可以透過自己的 GitHub 私有倉庫WebDAV，同步歌單、收藏、播放紀錄與統計。
 我覺得它比較特別的地方，是沒有把自己做成另一個中心化音樂平台，而是採用「本地優先」的方式。 歌曲、設定、播放紀錄和授權資料預設保存在自己的裝置上，需要跨裝置同步時，也能把資料存進自己控制的 GitHub 或 WebDAV，而不是上傳到開發者提供的伺服器。
