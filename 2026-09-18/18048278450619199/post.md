最近看完 Lauren poteto 的 pstack Pt.2。

如果 Part 1 的重點是：
Verification is all you need.

那 Part 2 我會把它濃縮成一句：
AI Coding 真正需要的不是更長的 Plan，而是更好的 Context + Evidence。
---
以前寫大型功能，我們通常會：
讀 Code
↓
建立 Mental Model
↓
寫 Design Doc
↓
開始實作
現在 Agent 可以瞬間讀很多 Code，

但新的問題變成：
它到底有沒有真的理解你的系統？

Lauren 認為 Agent 常見的失敗，大概有兩種：
1️⃣ 沒真正理解你的 Intent
2️⃣ Context 不夠完整，所以在錯誤前提下做出「看似合理」的東西

所以她不是一開始就叫 Agent：
「幫我做這個功能。」
而是先叫它：
用你自己的話告訴我，你認為問題是什麼。

這招我覺得超實用。
因為在 AI 開始寫 Code 前，
你就可以先抓出：
「等等，你根本理解錯了 」
