最近逛到一個很適合做高質感 Web 3D 的開源元件庫：ThreeUI
簡單說，它有點像：
「Three.js 世界的 shadcn/ui + 視覺特效元件庫。」

不用每次從零開始刻 Shader、粒子、3D 背景，可以直接把做好的 React 元件拿進專案改。

Community 版目前有：
－50 個 Parent Components
－164 個可瀏覽效果
－完整 Source Code
－可直接 npm 安裝
－MIT License
裡面的東西也不是普通 Button / Card，而是：
🌊 Liquid Background
🌐 Globe
🌳 Generative Tree
🌀 Typography Vortex
🌌 Void / Warp Field
🔥 Ember Storm
🚪 Portal Field
甚至有 Liquid Metal、Plasma、Ignition 這類互動按鈕，還有完整的 Three.js 場景。
