## 資料夾怎麼排

- `YYYY-MM-DD/`：該日（台北時間）發布的貼文。
- `YYYY-MM-DD/<貼文 ID>/post.md`：該則文字、時間、是否為回覆。有圖或影片時列在「媒體」。
- 同一個資料夾裡的圖片、影片，就是該則貼文的媒體。一則多圖會放在一起。
- 沒有媒體的純文字貼文，資料夾名稱是 `t` 加上 Unix 時間戳；若同一秒有多則，後面再加序號。
- 有媒體時，資料夾名稱用第一個媒體檔的數字 ID。
- `index.json`：全部貼文索引，欄位有日期、時間、標題（內文第一行）、路徑、是否為回覆、媒體數量。

## 整理時的處理

- 官方匯出裡的貼文文字是錯誤編碼（UTF-8 被當成 Latin-1）。備份裡已還原成 UTF-8。
- 匯出檔沒有貼文永久連結（permalink），所以每則只註明「匯出檔未提供」。
- 少數媒體檔原本沒有副檔名，已依檔案格式補上（例如 `.jpg`、`.mp4`）。
- 草稿圖片，以及沒有被任何貼文引用的媒體，沒有放進來。
