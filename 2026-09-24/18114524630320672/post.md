如果你想在自己的產品裡塞進一套「Google Sheets + Docs + Slides」，其實不一定要全部自己刻
最近看到一個很完整的開源專案：Univer。
 它不是單純的 Excel Viewer，而是一套可以嵌進自己產品裡的 Office SDK。
目前涵蓋： 
Spreadsheet
Document
Presentation
Bases
Boards
而且官方現在直接把它定位成： The Office Harness for AI Agents 也就是不只讓「人」編輯 Office 文件，還想讓 AI Agent 可以直接讀、改、驗證 Office 內容。 
它可以做到： 
📊 Agent 修改 Workbook 
Range 
Formula
📝 程式化編輯文件
🖼️ Render 後截圖驗證結果 
🌳 Agent 在隔離的 Worktree 修改，再交給人 Review 🖥️ Browser 有完整 UI ⚙️ Node.js 又可以 Headless 執行
