最近逛到一個滿適合做網頁 3D 視覺與 WebGL 動畫的開源工具：TroisJS。

簡單說，它是一個專為 Vue 3 打造的 Three.js 封裝庫，幫你把那些「需要手寫一堆底層 WebGL 邏輯與繁瑣的 Three.js 初始化設定」，變成可以直接用 Vue 標籤語法輕鬆堆疊出來的 3D 場景。

－完美整合 Vue 3 與 Three.js，提供如 `<Scene>`、`<Camera>` 等直覺的組件化標籤，讓建立 3D 場景就像寫一般 HTML 一樣自然
－內建自動化的渲染迴圈與視窗響應縮放處理，省去開發者手動監聽瀏覽器變化與清理記憶體的麻煩
－支援豐富的進階功能，包含陰影運算、物理引擎整合，以及開箱即用的後處理特效

我覺得它適合做高度沉浸感的產品 3D 展示頁、品牌互動形象官網，或是需要將前端 UI 與 3D 模型緊密結合的 Web 應用程式。
