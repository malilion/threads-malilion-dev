什麼叫 Verification？ 
不是叫 AI 說： 「請確認程式碼有沒有問題。」 而是要真的給它工具，讓它可以：
🔍 操作 App 
🖱️ 點擊 UI 
📸 截圖 
🎥 錄製操作結果
🐛 Debug
📊 跑 Performance Trace 
🧪 執行 Test 
✅ 判斷功能到底有沒有成功
讓 Agent 形成真正的 Closed Loop： 
Implement → Run → Verify → Fix → Verify again 直到通過為止。 
pstack 裡有一個我覺得很值得抄的概念：
Build the Lever 與其寫一大篇 Markdown 告訴 Agent： 「登入後點這裡，再進設定頁，再按這個」
