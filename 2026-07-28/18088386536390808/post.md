最近逛到一個滿適合做網頁進階互動與流暢動畫的神級套件：GSAP (GreenSock Animation Platform)。 
簡單說，它是一個業界標準的 JavaScript 動畫函式庫，幫你把網站裡那些「想要做複雜的連續動畫或滾動視差，但用 CSS 或原生 JS 刻會寫到懷疑人生」的動態效果完美搞定。 
－具備極致的效能與跨瀏覽器相容性，動畫順暢度遠超傳統原生解法
 －提供強大的時間軸 (Timeline) 系統，可以精準控制多個動畫序列的播放、暫停與反轉 －擁有殺手級外掛 ScrollTrigger，讓「滾動觸發動畫 (Scrollytelling)」與視差效果變得超級直覺
