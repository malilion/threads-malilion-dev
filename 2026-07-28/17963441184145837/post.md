最近逛到一個很適合製作高質感 Vue 網站的開源工具：Vue Bits。

簡單說，它是一套以動畫和互動效果為主的 Vue 元件庫，也是 React Bits 的官方 Vue 版本。

很多網站裡那些「看起來很厲害，但自己從零刻會花很多時間」的文字動畫、動態背景、滑鼠特效與互動元件，都可以直接從這裡找到。

－有 Aurora、粒子球、光束、波浪、雷達與網格等背景效果
－提供 Blur Text、Split Text、Shiny Text、Count Up 等文字動畫
－也有 Carousel、Dock、Card Nav、Scroll Stack 等互動元件
－支援 Vue 3、TypeScript 與 Tailwind CSS
－可以透過 jsrepo 或 shadcn CLI，把元件原始碼直接加入專案。

我覺得 Vue Bits 最方便的地方，是 Vue 開發者終於也有一套完整的創意動畫元件庫。
以前看到很酷的 React 動畫元件，常常還要自己改寫成 Vue；現在可以直接找到對應版本，放進 Vue 或 Nuxt 專案使用。
