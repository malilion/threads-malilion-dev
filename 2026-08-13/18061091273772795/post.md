最近逛到一個滿適合做 AI 網頁自動化與資料萃取的開源工具：Orca (by stablyai)。

簡單說，它是一個專為LLM設計的網頁解析與自動化代理框架，幫你把原本需要手寫複雜爬蟲程式、分析混亂 DOM 結構與處理動態渲染的煩惱，轉化為一套只要賦予自然語言任務，AI 就能自動理解網頁並精準萃取資料的高效能工作管線。

－LLM 友善的網頁解析：能自動過濾雜亂的網頁原始碼，將複雜的 HTML 與 DOM 樹轉化為極度乾淨、適合大模型閱讀的結構化格式（如 Markdown 或簡化 JSON），大幅節省 Token 消耗。
－強大的視覺與節點定位：結合視覺感知與 DOM 節點映射技術，讓 AI 代理能像真人一樣精準辨識網頁上的按鈕、輸入框與關鍵資訊，降低對單一 CSS 選擇器的依賴。
－自動化互動與導航：不僅能「看」網頁，還能無縫驅動底層瀏覽器執行點擊、捲動、輸入文字等多步驟複雜操作，輕鬆應對現代動態網頁（SPA）與需要互動的場景。
－開箱即用的開發者體驗：提供清晰簡潔的 API 介面，並能輕鬆整合主流的瀏覽器自動化工具，讓開發者能快速打造出專屬的 Web Agent。
