AI 模型越來越會寫 Code，但真正卡關的常常是： 網頁還是要人點。
 填表、選時段、過驗證、完成預約——這些步驟一多，Agent 就卡住。
 簡單說，browser-use 是一個 開源 Browser Agent： 你用自然語言下任務，它就自己去操作瀏覽器。 官方 README 裡甚至用「預約路考」當例子：找空檔、選日期時間、處理 CAPTCHA、完成預約。 
它其實提供三條路： 
－全託管 Cloud：Agent + 瀏覽器都交給他們跑 －CLI：把瀏覽器能力接進你現有的 coding agent
－Python Library：在自己的程式裡本地跑開源 Agent 技術上比較有料的點： 可以接 Claude / GPT / 自備模型；瀏覽器可以是本地，也可以走他們的 cloud browser。
