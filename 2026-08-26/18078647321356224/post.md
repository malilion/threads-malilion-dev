最近逛到一個很適合做網站互動動畫的工具：Motion。

如果你以前用過 Framer Motion，那它就是現在獨立發展後的 Motion。

簡單說，它是一套給 Web 使用的動畫函式庫，可以很快速地幫網站加入進場動畫、Hover、Drag、Scroll、Layout Transition、Spring 等互動效果，而且目前支援 React、JavaScript 與 Vue。

－支援 React、JavaScript、Vue
－可以做 Scroll-linked Animation
－支援 Hover、Press、Drag 等 Gesture
－內建 Spring Physics
－支援 Layout Animation
－可以處理元素離開畫面的 Exit Animation
－能用 Variants、Stagger、Timeline 編排複雜動畫
－提供 430+ 個可以直接參考的動畫範例。
我覺得 Motion 最方便的地方，是很多原本需要自己處理 CSS Transition、事件監聽和 Animation State 的效果，可以直接用很直覺的方式描述。
