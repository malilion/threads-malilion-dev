最近逛到一個很有趣的前端視覺開源專案：Pokémon Cards CSS。

簡單說，它用 CSS + Svelte 做出了寶可夢卡牌那種會隨著角度變化的「全息閃卡效果」。

滑鼠移動到卡片上時，卡面會跟著傾斜，反光、彩虹漸層、亮片與 Holofoil 紋理也會一起改變，看起來真的很像拿著實體卡牌在燈光下面轉動。

－使用 SvelteJS 製作互動
－大量運用 CSS Transform
－透過 CSS Gradient 模擬彩虹反光
－使用 Blend Mode 疊加不同光澤與紋理
－搭配 Filter 製作亮度、色彩與 Holofoil 效果
－可以依照不同寶可夢卡牌類型做出不同的反光樣式
－不需要 Three.js 或 WebGL，也能做出很有立體感的互動效果。
