最近逛到一個很適合做 AI 故事短片的開源專案：story-to-handdrawn-video。
簡單說，它可以把：
故事文字 → 分鏡 → 手繪插畫 → 動畫影片
整套流程串起來。
你只要丟一段中文故事，Agent 會自動分句、安排節奏與畫面，再用 Remotion 做成 3:4 直式手繪故事動畫。
－支援文字直接生成影片
－也能把現有圖片依序做成動畫
－內建 20 種手繪風格
－支援彩鉛、水彩、水墨、蠟筆、Zine、白板等風格
－有「文字 → 黑白草稿 → 彩色插畫」揭示動畫
－可加右下角卷頁翻書效果
－正式輸出 1080×1440
－支援 Codex、Claude Code、Kimi Code 等 Agent Skill。
