如果你只是想把現在的 AI Coding Agent 用得更熟，可以走：
Track A — CLI Power User
從 Claude Code、Codex、OpenCode、Gemini CLI 開始，學 CLAUDE.md、Slash Command、MCP、CI 自動化與實際工作流程整合。
如果你的目標是：
「我想自己做一個 Agent。」
那就走：
Track B — Agent Builder
會一路碰到 Function Calling、ReAct、Agent Framework、MCP、RAG、Long-term Memory、Multi-Agent Orchestration，一直到 Production 等級的 Eval 和 Observability。
