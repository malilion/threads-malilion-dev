最近逛到一個超硬核又極致優雅的 3D 網頁遊戲開源專案：moon-rover (by winchxyz)。

簡單說，它是一個「純原生打造的 3D 登月車探勘遊戲」，幫你把開發網頁遊戲對龐大引擎與素材庫的依賴，轉化為一套極簡、輕量且完全靠程式碼即時生成一切的技術藝術品。

－極致輕量的零建置：無需 Webpack、Vite 或任何繁瑣的環境設定，純原生 JavaScript 寫成，打開瀏覽器就能直接運行，回歸最純粹的 Web 開發體驗。
－純原生的 WebGL2 實作：完全不依賴 Three.js 或 Babylon.js 等第三方 3D 引擎，直接與底層圖形 API 溝通，展現了極其深厚的技術底蘊。
－零第三方素材：這點最狂！遊戲中你看到的所有地表材質貼圖，以及聽到的所有環境音效，全都是在runtime透過程式碼即時運算生成的。
－精巧的程序化生成：以極小的專案體積完美實現複雜的 3D 渲染與物理互動，是學習圖形學與網頁底層運作的絕佳教科書。
