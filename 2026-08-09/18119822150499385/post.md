最近逛到一個滿適合做網頁介面與 App 視覺設計的開源圖示庫：MingCute Icons (by mingcute-design)。

簡單說，它是一個「極簡且精緻的開箱即用向量圖示系統」，幫你把原本需要到處拼湊風格、甚至自己辛苦繪製 SVG 的煩惱，轉化為一套只要引入程式碼或匯入 Figma 就能瞬間提升產品視覺質感的現代化設計資源。

－極簡與高質感的視覺語彙：提供大量線條俐落、細節圓潤且風格高度統一的圖示，專為現代 UI/UX 設計打造，能完美融入各種網頁與行動應用介面。
－開箱即用的跨框架支援：不僅提供原始 SVG 檔案與 Web Font，還原生整合 React 與 Vue 等主流前端框架，開發者只需將其作為元件引入，即可輕鬆動態調整顏色與尺寸。
－完全免費與商業友善：採用極度寬鬆的開源協議，允許個人與企業免費使用於商業專案，並讓設計師能自由修改線條與節點，無需擔心版權問題。
－豐富且分類完善的圖庫：涵蓋基礎操作、社群媒體、電商、開發工具等海量日常應用場景，並具備易於搜尋的官方圖示檢索網站，大幅節省找素材的時間。
